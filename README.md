# Visa Tracker (Android)

Track visa applications on your phone: details, status, history, and a one-tap link to the official status page.
All data stays on the device. No backend, no account, no passwords stored.

## Get the APK
1. Put these files in your GitHub repo (keep the folder structure) and push to `main`.
2. Open the repo > **Actions** > "Build Android APK" and wait for the green check (about 5-8 min).
3. Download the APK from **Releases > Visa Tracker (latest build)** (or Actions > run > Artifacts).
4. On your phone, open the APK and allow "Install unknown apps" when asked.

## Notes
- Statuses are entered by you after checking the official portal; the app never invents results.
- Official visa portals usually use CAPTCHA/login, so automatic checking is not included.
